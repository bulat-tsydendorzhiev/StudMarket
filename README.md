# StudMarket

Студенческий маркетплейс — платформа для размещения и поиска объявлений, что-то вроде небольшого Avito для студентов.

## Архитектура

```
Браузер
   |
   v
nginx (статику фронтенда + прокси /api)
   |
   +---- frontend (собранный Vite-билд, раздаётся nginx)
   |
   v
API Gateway
   |
   +---- Auth Service       ----> auth_db
   |
   +---- Listing Service    ----> listing_db
   |
   +---- Chat Service       ----> chat_db
```

- Наружу открыт только nginx (80/443). Порт **5173 (Vite) — только для локальной разработки**, не для продакшена.
- Фронтенд общается **только** с nginx по относительным путям `/api/...`; nginx проксирует их в API Gateway. CORS не нужен — всё same-origin.
- Каждый микросервис владеет собственной базой PostgreSQL.
- Сервисы общаются между собой только по REST.
- Сервисы не обращаются к чужим базам данных напрямую.

## Стек

- **Frontend:** React, TypeScript, Vite, React Router, TanStack Query
- **Backend:** Python, FastAPI, SQLAlchemy, Pydantic, Alembic, JWT
- **Инфраструктура:** Podman, Podman Compose, PostgreSQL, nginx

## Возможности

- Регистрация, вход, выход, текущий пользователь
- Объявления: создание, просмотр, редактирование, удаление
- Теги и фильтры
- Изображения объявлений (хранятся локально)
- Чаты и сообщения между покупателем и продавцом
- Непрочитанные сообщения
- Срок действия объявлений
- Профиль пользователя

## Запуск

### Требования

- [Podman](https://podman.io/) (с `podman compose` или `podman-compose`)

### Шаги

1. Скопируйте файл окружения:

   ```
   cp .env.example .env
   ```

2. Соберите и запустите:

   ```
   podman compose up -d --build
   ```

3. Откройте сайт: <http://localhost>

Контейнер `frontend` собирает статику в том `frontend-dist`, nginx ждёт успешного завершения сборки, раздаёт её и проксирует `/api` в API Gateway. Swagger API Gateway доступен на <http://localhost/api/docs>.

### Остановка

```
podman compose down
```

### Порты

| Сервис        | Порт (наружу) |
| ------------- | ------------- |
| nginx         | 80            |
| api-gateway   | только внутри сети |
| auth-service  | только внутри сети |
| listing-service | только внутри сети |
| chat-service  | только внутри сети |

## Деплой на VPS

- Всё из сборки работает на VPS без изменений (HTTP на 80).
- Для HTTPS: добавьте TLS-`server`-блок в `nginx/nginx.conf` (шаблон-комментарий уже там), смонтируйте сертификаты Let's Encrypt (certbot) в контейнер nginx и пробросьте порт 443. Рекомендуется redirect HTTP → HTTPS.
- Установите свой `JWT_SECRET` в `.env`.

## Локальная разработка

Backend поднимается в compose. Для активной работы с фронтендом (hot-reload):

1. `npm install` в `frontend/`
2. `npm run dev` — Vite стартует на :5173 и проксирует `/api` на `http://localhost:8000` (gateway).
3. Открывайте <http://localhost:5173>

## Правила проекта

- UUID для идентификаторов сущностей.
- Идентификатор пользователя берётся из JWT, никогда из тела запроса.
- Пароли не хранятся в открытом виде.
- Пользователи не могут создавать теги.
- Уведомления чата основаны на непрочитанных сообщениях.
